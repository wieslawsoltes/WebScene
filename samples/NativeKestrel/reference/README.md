# Original UI reference

These unchanged HTML/CSS files are from KestrelCAD commit
7a1e84c67fd24410c22f0d1a45b2e54120b32d0e (MIT; ../LICENSE).
They are fidelity references, not the current native application's entry point.
The HTML references upstream scripts/assets, which are not copied or deployed.

The native port must retain the original title bar, quick access, ribbon tabs,
ribbon groups, document tabs, drawing explorer, viewport overlays, properties,
command dock, status controls, menus and dialogs. Dynamic HTML generated by
upstream scripts must become predefined templates with matching classes and
structure. Extend compiler/engine support for the original markup and CSS;
do not replace missing features with a different UI design.

Known requirements beyond the initial compiler profile include CSS custom
properties and theme selectors, grid/minmax, attribute selectors, SVG icons,
input/select controls, overflow, typography, pseudo-elements and media queries.
Main.html/Main.css one directory above remain an integration scaffold until
these original structures and dynamic templates are ported and verified.
