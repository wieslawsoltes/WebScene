# AppScene developer guide

The application platform guide and current Kestrel host/build workflow now live in
[AppScene](https://github.com/wieslawsoltes/AppScene):

- [Developer guide](https://github.com/wieslawsoltes/AppScene/blob/main/docs/guides/appscene-developer-guide.md)
- [Kestrel sample](https://github.com/wieslawsoltes/AppScene/tree/main/samples/Kestrel)
- [Migration boundaries](https://github.com/wieslawsoltes/AppScene/blob/main/docs/migration.md)

WebScene continues to own its independently embeddable engine, HTML/CSS compiler,
native document APIs, optional JavaScript runtime and native interop generation.
Existing Foco samples remain historical integration examples; AppScene is the
canonical home for the extracted macOS application host and Kestrel packaging.
